# 酒馆 Agent v0.1：安装与使用

酒馆 Agent 是一个 Windows 优先、本地保存数据的角色扮演对话系统。电脑保存 Provider
凭据、会话、角色卡、世界书、预设与学习结果；电脑浏览器、手机浏览器和 APK 都只是访问
同一台电脑宿主。

公开版不附带任何用户内容。首次启动后角色卡、世界书、预设和 Skill 列表为空是正常现象。

## 1. 安全默认值

- 本机入口只监听回环地址，不对局域网或公网开放。
- 手机入口只通过 Tailscale 私有 HTTPS 提供，不启用 Funnel。
- API Key 只保存在电脑端。
- Interactive、Learning、Maintenance 三条 Agent Lane 默认关闭。
- Maintenance 正式业务写入默认关闭。
- PostgreSQL/pgvector 是可选语义索引；SQLite 与本地文件仍是业务真值。
- 第一方 CommandCode Provider 源码随项目发布，但没有 Key、用户配置、安装态或存储。

## 2. 系统要求

必需：

- Windows 10/11 64 位
- Node.js `22.22.2`
- pnpm `10.33.0`
- Git
- Edge、Chrome 或其他现代浏览器

检查版本：

```powershell
node --version
pnpm --version
git --version
```

没有 pnpm 时安装锁定版本：

```powershell
npm install --global pnpm@10.33.0
```

手机私有访问还需要电脑和手机安装 Tailscale、登录同一 tailnet，并在 tailnet 中启用
MagicDNS 与 HTTPS Certificates。

自行构建 APK 还需要 JDK 17、Android SDK Platform 34、Platform Tools/adb，以及正确的
`JAVA_HOME` 和 `ANDROID_HOME`（或 `ANDROID_SDK_ROOT`）。

## 3. 获取源码与离线检查

```powershell
git clone https://github.com/conversition/jiuguan.git jiuguan
Set-Location jiuguan
pnpm install --frozen-lockfile
pnpm public:verify
pnpm typecheck
pnpm build
```

`public:verify` 是发布隐私门禁，不访问 Provider，也不读取其他安装的数据。

不要从旧安装或别人电脑复制这些目录/文件：

- `.env`、`.env.local`、`provider.json`
- `data/`、`.workbuddy/`
- 数据库、日志、缓存、会话和学习文件
- `node_modules/`、`dist-*`
- APK、AAB、keystore、签名密码
- 已安装插件和插件存储

## 4. 本机一键启动

双击根目录的：

```text
一键启动.bat
```

启动器会检查工具链、首次安装依赖、构建并同步第一方 CommandCode Provider，然后启动：

```text
Web：http://localhost:5173
API：http://127.0.0.1:17800
```

本机入口和手机私有入口共用：

```text
%LOCALAPPDATA%\Jiuguan\a9-private-data
```

停止服务请双击：

```text
停止.bat
```

本机入口和私有远程入口都使用端口 `17800`，不要同时启动；切换前先停止当前入口。

### 手动启动

终端一：

```powershell
$env:JG_USER_DATA_DIR = Join-Path $env:LOCALAPPDATA 'Jiuguan\a9-private-data'
$env:JG_DEV_WEB_PORT = '5173'
$env:JG_AGENT_PROFILE = (Resolve-Path 'tools/windows/public-safe-v0.1.env').Path
Get-Content -LiteralPath $env:JG_AGENT_PROFILE |
  Where-Object { $_ -and -not $_.StartsWith('#') } |
  ForEach-Object {
    $name, $value = $_ -split '=', 2
    Set-Item -LiteralPath ("Env:" + $name) -Value $value
  }
pnpm commandcode:provider:sync
pnpm web:server
```

终端二：

```powershell
pnpm web:dev
```

`JG_DEV_WEB_PORT=5173` 让后端只额外信任本机 Vite 开发页的 Origin；public-safe profile
确保手动启动与一键启动具有相同的 Agent 关闭边界。两个终端都必须从仓库根目录启动。

若要验证生产同源构建：

```powershell
$env:JG_USER_DATA_DIR = Join-Path $env:LOCALAPPDATA 'Jiuguan\a9-private-data'
pnpm web:prod
```

然后打开 `http://127.0.0.1:17800`。

## 5. 配置 Provider

推荐在页面的 Provider 面板完成：

1. 选择 Provider；
2. 填写 Base URL；
3. 填写模型名；
4. 在电脑端粘贴 API Key；
5. 保存并点击测试连接。

页面配置会写入电脑数据目录的 `provider.json`。它属于敏感文件，不要上传、截图或分享。

也可以创建仅供本机使用的环境文件：

```powershell
Copy-Item .env.example .env.local
```

常用字段：

```dotenv
JG_PROVIDER_ID=builtin.openai
JG_API_BASE=https://provider.example.com
JG_API_KEY=REPLACE_WITH_YOUR_KEY
JG_MODEL=model-name
JG_PROVIDER_KIND=openai
```

`.env.local` 已被 Git 忽略，但仍应按凭据保管。不要把真实值写进 README、Issue、命令输出
或提交历史。

### CommandCode Provider

在电脑的 `.env.local` 中设置：

```dotenv
COMMANDCODE_API_KEY=REPLACE_WITH_YOUR_COMMANDCODE_KEY
```

同步第一方 Provider：

```powershell
pnpm commandcode:provider:sync
```

随后在 Provider 面板显式选择 CommandCode 和模型。Key 由电脑宿主解析，不复制到浏览器或
APK。不要把独立回退端口 `3050` 暴露到局域网、Tailscale 或公网。

### PostgreSQL / pgvector（可选）

```dotenv
JG_PG_DSN=postgresql://USER:PASSWORD@127.0.0.1:5432/DATABASE
```

检查状态：

```powershell
pnpm pg:status
```

没有 PostgreSQL 时会回退 SQLite，不影响基本对话。

## 6. 导入自己的内容

启动后在页面中导入或创建你有权使用的：

- 角色卡；
- 世界书；
- 预设；
- 正则规则；
- Skill；
- 会话。

默认数据位置包括：

```text
%LOCALAPPDATA%\Jiuguan\a9-private-data\cards
%LOCALAPPDATA%\Jiuguan\a9-private-data\worldbooks
%LOCALAPPDATA%\Jiuguan\a9-private-data\presets
%LOCALAPPDATA%\Jiuguan\a9-private-data\skills
```

公共源码不会自动下载或补齐任何私人素材。

如需从自己的 SillyTavern 世界书导入文风条目，可显式指定源文件：

```powershell
$env:JG_STYLE_SRC = 'C:\Path\To\your-style-worldbook.json'
pnpm style:import
```

公开版没有默认文风源路径，也不会生成任何内置作者文风。

## 7. 手机浏览器访问

### 一次性准备

1. 电脑和手机安装 Tailscale；
2. 两端登录同一个 tailnet；
3. 在 Tailscale 管理页面启用 MagicDNS；
4. 启用 HTTPS Certificates。

### 每次启动

确认端口 `17800` 没有被本机入口占用，然后双击：

```text
私有远程启动.bat
```

接受 UAC。启动器会临时启动 Tailscale、构建生产 Web、启动设备认证，并显示一个
tailnet-only HTTPS 地址。它不会配置开机自启动。

手机操作：

1. 打开 Tailscale 并确认已连接；
2. 用浏览器打开启动器显示的 HTTPS 地址；
3. 首次使用时输入电脑现场显示的配对码；
4. 配对后即可访问电脑上的同一份会话和资产。

配对码只显示一次、15 分钟有效，使用后失效。不要截图或发送给其他人。

如果尚未建立任何有效管理员设备，首次配对码丢失或过期，可在服务运行时双击：

```text
手机配对码.bat
```

若已经存在有效管理员设备，bootstrap 脚本拒绝再签发属于正常安全行为。请在已配对的
管理员页面进入“设备与安全 → 生成 Web 配对码”，再为新设备签发。

停止私有入口：

```text
停止.bat
```

停止器会撤销本轮 Tailscale Serve、执行 `tailscale down`，并停止本轮由酒馆启动的服务。

## 8. 构建 APK（可选）

v0.1 推荐先使用手机浏览器。APK 在构建时固定一个精确的 Tailscale HTTPS origin，不能
直接使用为另一个 tailnet 构建的包。

取得自己的私有 HTTPS 地址后：

```powershell
$env:JAVA_HOME = 'C:\Path\To\JDK-17'
$env:ANDROID_HOME = Join-Path $env:LOCALAPPDATA 'Android\Sdk'
$env:JG_PINNED_ENDPOINT = 'https://your-host.your-tailnet.ts.net'

pnpm mobile:doctor
pnpm mobile:apk:debug
```

连接并授权 Android 手机后：

```powershell
pnpm mobile:install
pnpm mobile:smoke
```

Release 包还要求干净 Git 工作区和用户自己创建的 keystore。keystore、密码、APK 以及
`keystore.properties` 均不得提交到 GitHub。

## 9. 数据备份与升级

先执行 `停止.bat`，再备份：

```text
%LOCALAPPDATA%\Jiuguan\a9-private-data
```

该目录可能含 Provider Key、会话和设备认证材料，备份也属于敏感数据。

升级源码：

```powershell
.\停止.bat
git pull --ff-only
pnpm install --frozen-lockfile
pnpm public:verify
pnpm typecheck
pnpm build
.\一键启动.bat
```

源码升级不会主动删除用户数据目录。

## 10. 常见问题

### 首次启动没有角色卡或世界书

这是公开清洁版的预期行为，请导入自己的内容。

### 端口 17800 被占用

先运行 `停止.bat`。不要同时运行本机与私有入口。

### 手机打不开 HTTPS 地址

运行：

```powershell
pnpm private:status
```

确认手机 Tailscale 已连接、两端属于同一 tailnet、MagicDNS 与 HTTPS Certificates 已启用，
并使用本轮启动器显示的地址。不要启用 Funnel 或公网端口映射。

### 手机提示没有权限

设备 session 可能过期或被吊销。由有效管理员重新生成配对码。不要通过关闭认证来绕过。

### 电脑和手机数据不同

确认两种入口都使用 `%LOCALAPPDATA%\Jiuguan\a9-private-data`，不要让其中一个入口改用
源码树内的 `data/`。

### Provider 请求失败

在 Provider 面板重新测试 Base URL、模型名与 Key；检查 Base URL 是否重复包含 API 路径。
CommandCode 用户同时检查电脑侧网络或本机代理。不要开放 `3050` 给手机。

### Agent 面板全部显示关闭

这是 v0.1 的安全默认，不是安装失败。主对话不依赖这些实验 Lane。开放真实 Agent 必须先
确定精确会话、调用次数、费用、写入范围和回滚策略；公开版不会替用户自动授权。
